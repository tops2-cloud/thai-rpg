# ⚔️ ตำนานผู้กล้า — Thai RPG

เกม RPG ผจญภัยแบบเทิร์นเบส ภาษาไทย เล่นบนเว็บ/มือถือได้ทันที

## ฟีเจอร์
- **3 อาชีพ**: นักรบ 🧔🏻‍♂️ / จอมเวท 🧙🏻 / นักธนู 🧝🏻 — แต่ละอาชีพมี 2 สกิล (สกิลที่ 2 ปลดล็อก Lv.5)
- **ต่อสู้แบบเทิร์นเบส**: โจมตี, สกิล (ใช้ MP), ป้องกัน, ใช้ยา, หนี
- **เก็บเลเวล**: ได้ EXP จากการชนะ เลเวลอัพแล้วค่าสถานะเพิ่มและฟื้นฟูเต็ม
- **4 พื้นที่ + 4 บอส**: ป่าเขียวขจี → ถ้ำมืดมิด → ภูเขาไฟ → ปราสาทจอมมาร
  - ล่ามอนสเตอร์ 5 ตัวในพื้นที่เพื่อปลดล็อกบอส
  - บอสจะ "ชาร์จพลัง" ทุก 3 เทิร์น — กดป้องกันเพื่อรับท่าไม้ตาย
  - ชนะบอสเพื่อเปิดพื้นที่ถัดไป
- **สะสมไอเทม**: อุปกรณ์ 3 ช่อง (อาวุธ/เกราะ/เครื่องประดับ), 4 ระดับความหายาก (ธรรมดา/หายาก/มหากาพย์/ตำนาน) + ไอเทมบอสเฉพาะ
- **สมุดสะสม**: บันทึกไอเทม 40 แบบ และมอนสเตอร์ที่เคยปราบ
- **หมู่บ้าน**: โรงเตี๊ยม (พักฟื้น), ร้านค้า (ยา + หีบสมบัติสุ่ม)
- **เซฟอัตโนมัติ** ในเบราว์เซอร์ (localStorage)

## ไฟล์
- `index.html` — หน้าเว็บ
- `style.css` — หน้าตา
- `game.js` — ตรรกะเกมทั้งหมด (ข้อมูลมอนสเตอร์/ไอเทมอยู่ด้านบนไฟล์ แก้ตัวเลขได้ง่าย)
