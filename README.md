# ⚔️ ตำนานผู้กล้า — Thai RPG

เกม RPG ผจญภัยแบบเทิร์นเบส ภาษาไทย เล่นบนเว็บ/มือถือได้ทันที

## ฟีเจอร์
- **3 อาชีพ**: นักรบ / จอมเวท / นักธนู — ตัวละครเต็มตัว ภาพเปลี่ยนตามอุปกรณ์ที่สวม
- **ต่อสู้แบบเทิร์นเบส**: โจมตี, สกิล (ใช้ MP), ป้องกัน, ใช้ยา, หนี
- **10 ด่าน 10 บอส**: ป่า → ถ้ำ → ทะเลทราย → ภูเขาไฟ → หนองน้ำพิษ → ธารน้ำแข็ง → วิหารใต้สมุทร → เกาะลอยฟ้า → ดินแดนวิญญาณ → ปราสาทจอมมาร
  - ล่ามอนสเตอร์ 5 ตัวเพื่อปลดล็อกบอส, บอสชาร์จท่าไม้ตายทุก 3 เทิร์น (กดป้องกัน)
  - บอสทุกตัวดรอปไอเทมบอสเฉพาะ (มีภาพบนตัวละคร เช่น ปีกพญาครุฑ, ตรีศูลสมุทร)
- **3 ระดับความยาก** (ปลดล็อกเมื่อจบเกมโหมดปกติ):
  - 🟢 ปกติ — ไอเทมสูงสุดระดับตำนาน
  - 🟠 ยาก — มอนสเตอร์ +28 เลเวล แข็งขึ้น, บอสคลั่งเมื่อเลือด < 30%, ดรอประดับเทพนิยาย
  - 🔴 ขั้นสูง — มอนสเตอร์ +56 เลเวล แข็งมาก, บอสคลั่งเมื่อเลือด < 50%, ดรอประดับเทพเจ้า
  - เลเวล/ทอง/ไอเทมติดตัวข้ามโหมด, ความคืบหน้าด่านแยกตามโหมด
- **ไอเทม 6 ระดับ**: ธรรมดา → หายาก → มหากาพย์ → ตำนาน → เทพนิยาย → เทพเจ้า (+ ไอเทมบอส)
- **อาวุธระดับสูง** (ดรอปด่าน 5+): ดาบใหญ่, ง้าว, เคียวมรณะ, คทาคริสตัล, หน้าไม้
- **ตีบวก +1 ถึง +15** ที่ช่างตีเหล็ก: ค่าพลัง +10% ต่อขั้น
  - +1 ถึง +7 ล้มเหลวไม่ลดระดับ, ตั้งแต่ +7 ล้มเหลวจะลด -1 (ใช้ 🧿 ยันต์คุ้มครองกันได้)
  - +7 ขึ้นไปอาวุธเรืองแสง, +10 ขึ้นไปมีประกาย
- **สมุดสะสม** ไอเทม 94 แบบ + มอนสเตอร์ 40 ตัว
- **เซฟอัตโนมัติ** ในเบราว์เซอร์ (เซฟเวอร์ชันเก่าอัปเกรดให้อัตโนมัติ)

## ไฟล์
- `index.html` — หน้าเว็บ
- `style.css` — หน้าตา
- `hero.js` — วาดตัวละคร + อุปกรณ์ (SVG)
- `game.js` — ตรรกะเกมทั้งหมด (ข้อมูลด่าน/ไอเทม/ความยากอยู่ด้านบนไฟล์ แก้ตัวเลขได้ง่าย)
